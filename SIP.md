# 🔍 Signal Integrity Protocol (SIP) — Affective Version

**Purpose:**  
To detect affective distortion (ΔS_aff spikes) and initiate the Affective Containment chain (SVD → AEB → SMP).

---

## 🧠 Function
| Signal Type | SIP Action | Escalation |
|--------------|-------------|-------------|
| Emotional Overload | Flag ΔS_aff spike | Route to SVD (Reflective Reframing). |
| Manipulative or guilt-driven speech | Flag as ego-reward attempt | Trigger AEB (Ego Disengagement). |
| Low emotional input / Neutral tone | No action | Pass through for standard reasoning. |

---

SIP ensures that AI does not absorb emotional chaos.  
It converts affective noise into clean cognitive data for structural use.
